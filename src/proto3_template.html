      Learn · scripts of the Buddhist world

      Read the stones yourself.

      Write a name or a line in Dhamma Lipi, Pāli and the other scripts that carried the teaching. Paste letters from an inscription in any of them to read it back.

      Choose a script

      How the reading works
      • Typing in हिंदी or मराठी gives the most exact result, because those letters map one to one onto the old scripts.
      • In English, write long vowels twice: aa, ee, oo. A name keeps its final a, as Hindi and Marathi do, so “Mayur” is read ma-yu-ra. For the exact spelling type it in Hindi or Marathi: मयूर gives ma-yū-ra.
      • For Pāli lines, type the marks so endings stay right, for example dhammaṃ saraṇaṃ gacchāmi.
      • Paste letters in Dhamma Lipi, Kharoṣṭhī, Siddham, Sinhala, Burmese, Thai or Devanāgarī and the page reads them back.
      • This changes the script, not the language. It does not translate English into Pāli.

      Explore · traditions

      Streams, not boxes

      Buddhist traditions are often drawn as separate boxes. History looks more like rivers: they divide, run side by side, share water and carry on. Time runs downwards; regions run west to east.

      Each stream's text is reviewed by a scholar and, where appropriate, a practitioner of that tradition. No stream is called original, pure or lesser.

      Dhamma Saṅgīti · the great councils

      When the monks gathered to remember

      Saṅgīti means “reciting together”. For centuries nothing was written down: the Buddha’s words lived only in the memory of monks. Whenever that memory seemed in danger, they gathered to chant the teaching aloud and agree on every word.
