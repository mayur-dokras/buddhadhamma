# BuddhDhamma.in

An interactive guide to the Buddha's teaching and how it travelled, in English, हिंदी and मराठी. It has a 3D doorway, a map of Buddhist Asia with the routes of Faxian and Xuanzang, courses taught by specialists with expert sign in and a profile dashboard, the Lumbinī inscription in Dhamma Lipi read word by word, the mudrās, the great mahāvihāras, the Dhamma Saṅgītis (councils), fragments from 20 regions and an archive of primary sources.

## Run it locally
The site is plain HTML and JavaScript. No framework and no npm install.

In VS Code, install the Live Server extension, then right-click `index.html` and choose Open with Live Server.

Or from a terminal

```bash
python -m http.server 8000
# then open http://localhost:8000
```


## Editing workflow
1. Change markup, CSS or JS in `src/proto3_template.html`, or data in the `data_*.js` files.
2. For new interface text, add a row to `src/i18n_src.py` or `src/i18n_extra.json`, then run `python src/i18n_src.py`.
3. Rebuild with `python src/build.py`, which refreshes `index.html`.
4. Reload the browser.

Requires Python 3.8 or newer (standard library only).

## Courses and expert accounts
The Courses page, expert sign in and the expert dashboard run on a small data layer, `window.BD_API`, defined in `src/proto3_template.html`. Until a database is connected it keeps accounts and courses in the visitor's own browser (preview mode). To go live, replace `window.BD_API` with one backed by Supabase or Firebase that has the same methods.

## Join form
On a static host the Join form opens the visitor's email app addressed to connect@buddhadhamma.in. To collect sign-ups automatically, connect a form service such as Formspree or Google Forms by defining `window.BD_SIGNUP = async record => { ... return true; }` in a small script before `</body>`.

## Checks
Every push runs the Site check workflow. It rebuilds index.html from src, fails if the committed files differ from the rebuild, checks that every script parses and that every image the data points to exists. Run the same check locally with `python src/build.py && python scripts/check_site.py`.

Work on a branch, push it, wait for the check to pass, then merge into main.

## Deploy on GitHub Pages
Push to GitHub, open Settings, then Pages, and choose the `main` branch with the root folder. `index.html` is served as it is.
